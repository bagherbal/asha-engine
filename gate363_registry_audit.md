## 1. Modular operator formalization

Gate 363 installs the finite modular-flow formalism.

For a faithful finite state with density matrix `rho`, the modular flow acts on matrix units as:

```text
sigma_t(E_ij) = (rho_i/rho_j)^(it) E_ij
              = exp(i t log(rho_i/rho_j)) E_ij
```

The modular Hamiltonian is:

```text

```

and the formal Tomita-Takesaki flow is:

```text

```

The modular conjugation is linked to the ASHA real structure by requiring the flow-level conjugation to preserve the Gate-293 `J_swap` particle-antiparticle pairing inside the GNS/state representation.
