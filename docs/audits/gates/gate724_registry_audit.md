## Core audit

The no-bias state on the sealed four-real Higgs carrier is:

```text
rho_plus = I_K7+ / 4.
```

For a rank-one radial projector:

```text
P_rad^2=P_rad
P_rad^T=P_rad
rank(P_rad)=1
```

one obtains:

```text
Tr(rho_plus P_rad)=1/4.
```

Define the phase-loop payoff observable:

```text
R_phase=(1/(2*pi))P_rad.
```

Then:

```text
Tr(rho_plus R_phase)
= (1/4)(1/(2*pi))
= 1/(8*pi).
```

## Firewalls

The hypercharge normalization `q` rescales the phase generator; it does not source the geometric event weight or the HistoryLoopUnit coefficient.  The `7/72` coefficient remains the K7 event probability in the boundary-history lane and does not source `1/4` or `1/(8*pi)`.
